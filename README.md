## 📌 Overview

A sleek, modern authentication interface featuring smooth tab switching between Login and Signup modes. Designed with modern CSS glassmorphism, responsive inputs, and real-time client-side field validation.

---

## ✨ Key Features

- **Dual-Mode Toggle:** Seamless transition animation between Sign In and Sign Up states.
- **Interactive Validation:** Real-time email format verification, password length checks, and error highlighting.
- **Password Visibility Switch:** One-click toggle between masked password and plain text view.
- **Universal Accessibility:** Semantic HTML form elements styled for touch devices and keyboard navigation.

---

## 💻 Tech Stack & Architecture

- **Markup:** Semantic HTML5
- **Styling:** CSS3 Flexbox, Custom Properties, Smooth Keyframe Transitions
- **Interactivity:** Vanilla JavaScript (DOM Events, Regex Validation)
